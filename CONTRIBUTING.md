# Contributing

Use a genuine issue → branch → pull request workflow for meaningful changes. Include acceptance criteria, tests, and accurate documentation. Suggested branches use `feature/<name>` and commits use clear conventional prefixes such as `feat:`, `fix:`, `test:`, or `docs:`.

Before opening a pull request, run `python -m pytest`. For Blender changes, also run the local demo and inspect both the PNG and MP4. Never add API keys, unlicensed assets, fabricated screenshots, fake collaborators, or activity created only to pursue an achievement.
