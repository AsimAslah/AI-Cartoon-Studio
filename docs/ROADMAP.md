# Roadmap

- **v0.1.0 Working foundation — RELEASED 2026-11-23:** Blender discovery, procedural fox/forest, basic animation, editable blend, PNG/MP4 demo, tests, CI, and public release.
- **v0.2.0 Storyboard editor and project persistence — MERGED, NOT RELEASED:** versioned scene editing, validation, reordering, atomic JSON project storage, single-scene deterministic rendering, and honest render states. Multi-scene video sequencing remains planned.
- **Malayalam lip-sync Milestone 1 — IMPLEMENTED ON FEATURE BRANCH:** local-only image/video/audio validation, UUID storage, browser previews, provider availability, and background job contracts. No real provider or animal inference has been verified.
- **Malayalam lip-sync Milestone 2:** user-approved CUDA/external provider, decoded duration/codec validation, Malayalam synchronization, animal compatibility trials, and visibly verified MP4 output.
- **AI Video Studio Milestone 2 — IMPLEMENTED:** secure reference uploads, official LTX-2.5 Gradio adapter, schema verification, explicit remote consent, truthful jobs, and `ffprobe` output gating.
- **AI Video Studio Milestone 2.6 — COMPLETED:** read-only ZeroGPU diagnostics, sanitized provider-error classification, selected-settings reservation checks, and a one-attempt low-resource preset.
- **AI Video Studio Milestone 2.7 — TECHNICALLY VERIFIED:** one real 1024×576 LTX-2.5 MP4 passed FFprobe, byte-identity, frame-uniqueness, and visual inspection. The clip proves the provider pipeline but has composition and character-consistency limitations; the complete WOODORA advertisement is not assembled.
- **Video Timeline Studio Milestone 4 — IMPLEMENTED ON FEATURE BRANCH:** local MP4 upload/import, FFprobe metadata and thumbnails, reorder/trim/preview, optional voice and music mixing, versioned project persistence, and independently verified 720p/1080p FFmpeg export. Creative assembly and approval of the complete WOODORA advertisement remain user work.
- **Cinematic Advertisement Workflow Milestone 5 — IMPLEMENTED ON FEATURE BRANCH:** optional ten-scene WOODORA planner, still-image scenes, safe titles/text/logo overlays, fades and crossfades, brightness/contrast, audio offsets, character-reference records, schema `1.1` persistence, and verified local FFmpeg export. Planned scenes are not generated or marked complete.
- **v0.3 Animation pipeline:** reusable action library, multiple scenes, camera templates.
- **v0.4 Audio:** narration import, legal sound assets, optional reliable offline TTS.
- **v0.5 Web application:** queued rendering, durable progress, previews, downloads.
- **v0.6 Improved automation:** more assets, consistency controls, optional local AI provider.
- **v1.0 Stable:** reproducible setup, polished UI, documented limitations, examples.

Only v0.1.0 is currently released. Later versions are development targets.
