# Roadmap

- **v0.1.0 Working foundation — RELEASED 2026-11-23:** Blender discovery, procedural fox/forest, basic animation, editable blend, PNG/MP4 demo, tests, CI, and public release.
- **v0.2.0 Storyboard editor and project persistence — IMPLEMENTED, PENDING REVIEW:** versioned scene editing, validation, reordering, atomic JSON project storage, single-scene deterministic rendering, and honest render states. Multi-scene video sequencing remains planned. Tracked by [issue #3](https://github.com/AsimAslah/AI-Cartoon-Studio/issues/3).
- **v0.3 Animation pipeline:** reusable action library, multiple scenes, camera templates.
- **v0.4 Audio:** narration import, legal sound assets, optional reliable offline TTS.
- **v0.5 Web application:** queued rendering, durable progress, previews, downloads.
- **v0.6 Improved automation:** more assets, consistency controls, optional local AI provider.
- **v1.0 Stable:** reproducible setup, polished UI, documented limitations, examples.

Only v0.1.0 is currently released. Later versions are development targets.
